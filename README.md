## ✨ Features

- **7,298 Illustrated Vocabulary Cards:** Every word comes with a hand-curated painting visualizing real-world context.
- **Human Editorial Vietnamese Guidance:** Real-world usage tips, collocations, and IELTS scoring hints written by humans with zero AI clichés.
- **FSRS Spaced Repetition:** Powered by the open-source Free Spaced Repetition Scheduler (as featured in modern Anki) to optimize retention without burnout.
- **3D WebGL Galaxy:** 7,298 words organized into an interactive celestial star map across 19 IELTS topic clusters.
- **Typing Studio:** Practice muscle memory and spelling through 3 distinct typing modes (Word, Sentence, Dictation).
- **Focus Soundscapes:** 7 built-in ambient background soundscapes (Rainy Library, Starlight, Morning Forest, Ocean, Fireplace, etc.).
- **Local-First Privacy:** Zero sign-up, zero tracking. All your progress stays securely inside your browser's local storage and can be backed up as JSON anytime.

## 🚀 Quick Start

### Prerequisites
- Node.js 20+
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/zhugez/lexastra.git
cd lexastra

# Install dependencies
npm ci

# Start local development server
npm run dev
```

Open **http://localhost:5188** in your browser.
